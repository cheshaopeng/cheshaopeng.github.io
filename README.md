# Shaopeng Che — Academic Website

Production site for **https://cheshaopeng.github.io/**.

## Deploy

Upload the **contents of this folder** to the root of the `cheshaopeng/cheshaopeng.github.io` repository (do not upload the enclosing folder itself).

Then in GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

The site is plain static HTML/CSS/JS and includes `.nojekyll`.

## Photo/content management

This repository contains `.pages.yml` for Pages CMS. Sign in at https://app.pagescms.org with GitHub, install/authorize the Pages CMS GitHub App for this repository, and open the repository. The CMS can edit Publications, Projects and Moments. Moment images are stored in `assets/images/moments/`.
